Píxel de Meta (Facebook e Instagram)

El formulario manda InitiateCheckout al abrirse y Purchase al crear el pedido (con precio, producto y cantidad).

API de conversiones (recomendado)

El servidor también manda cada compra directo a Meta, así se cuenta aunque el cliente tenga bloqueador de anuncios. No se cuenta doble: ambos llevan el mismo número de evento.

¿Cómo saco el token?
  1. Abre Administrador de eventos de Meta y elige tu píxel.
  2. Entra a Configuración.
  3. En «API de conversiones», toca Generar token de acceso.
  4. Cópialo y pégalo aquí (solo se muestra una vez).
